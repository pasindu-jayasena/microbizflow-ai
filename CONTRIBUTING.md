# Contributing

Issues and pull requests are welcome once the public repository is available. Describe the problem, proposed behavior, and how to reproduce or test it. Keep changes focused, add meaningful tests for behavior changes, and update documentation when setup or API behavior changes.

Never include real customer data, API keys, tokens, `.env` files, or live integration credentials. Use fictional sample data. Report security concerns privately as described in [SECURITY.md](SECURITY.md).

Run the project checks documented in [docs/testing.md](docs/testing.md) before submitting a pull request. The commands will be updated as tooling is added.

By contributing, you agree that your contribution can be distributed under the project's MIT License.
