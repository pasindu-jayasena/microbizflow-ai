# Security policy

This project is under development and is not yet suitable for storing real customer information.

Please report suspected vulnerabilities privately to the maintainer using GitHub's private vulnerability reporting feature once the repository is available. Do not open a public issue with exploit details or customer data. Include a minimal reproduction, affected revision, and likely impact. No response or remediation time is promised while the project is in its initial build phase.

Do not commit credentials. Keep local secrets in ignored files or deployment secret stores. The public demonstration will use fictional data and mock outbound messaging.
