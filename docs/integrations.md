# CRM synchronization

Booking creation and status changes enqueue business-scoped `crm_sync_events` in D1. The event key is unique and is reused for every attempt. The Worker claims a short lease, retries failures after 60 and 120 seconds, and moves an event to a dead-letter state after three failures. Owner activity shows attempts, retry time, provider, external record ID, latency, and final state without copying customer contact into the queue. Redacted customer records are skipped. The owner can run a bounded retry batch; the private hourly Cron and the local n8n workflow can also process due events.

The public demo uses the `mock` adapter and records `mock_synced`; it sends no CRM request. `external_synced` means the HubSpot API acknowledged an upsert. The adapter uses HubSpot's contacts batch upsert with `idProperty=email` and the stable event key as `objectWriteTraceId`. A failed or partial response stays eligible for retry. The adapter and fake HTTP response have unit tests; **no live HubSpot call has been verified** because a scoped development credential is not available yet.

For a synthetic development test only, create a HubSpot developer test account and a [Service Key](https://developers.hubspot.com/changelog/legacy-private-app-creation-sunset) with the minimum CRM contacts read/write scope. Save the key as `HUBSPOT_SERVICE_KEY` in ignored `.dev.vars`, set `CRM_PROVIDER=hubspot`, `CRM_EXTERNAL_ENABLED=true`, and `DEMO_MODE=false` on a private local Worker with fictional test contacts. Never add these settings to the public demo. The key is server-only. Test an upsert and retry, inspect the test contact in HubSpot, then remove it there. Before any real customer use, add recorded CRM-sharing consent, a provider deletion path, and a privacy review.

The provider endpoint and request shape follow [HubSpot contacts batch upsert](https://developers.hubspot.com/docs/api-reference/latest/crm/objects/contacts/batch/upsert-contacts). The adapter sends email, first name, and last name only; the event queue retains no duplicate contact content. A HubSpot network call is never made in demo mode even if a key is accidentally present.
