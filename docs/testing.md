# Testing

No application test suite exists yet. The development-environment milestone will add commands for unit, API integration, type, lint, and end-to-end checks. Test reports in this file must list commands and actual results, including failures.

The highest-risk planned cases are overlapping and simultaneous bookings, duplicate submission keys, invalid state transitions, owner authorization, input validation, AI fallback, workflow retries, and outbound approval gates. The deployed demo also needs an end-to-end booking check against its public HTTPS URL.
